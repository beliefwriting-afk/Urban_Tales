# tools/ —— 離線工具鏈（Python）

這個目錄放**離線執行**的輔助腳本。它們：

- ❌ 不部署、不進 runtime、不被應用程式匯入
- ❌ 不參與 CI 的建置判定
- ✅ 可以用 Python 寫

## 判準

> 這個腳本的產出**會不會被 CI 拿來決定建置過不過**？
>
> - **會** → 必須是 TypeScript，放 `scripts/`
> - **不會** → 放這裡，語言隨意

## 為什麼 `content:check` 不能放這裡

因為它跟執行期共用 `content/schema.ts` 的 Zod 定義。若改用 Python 的
pydantic 另寫一份，就會有**兩份會漂移的 schema**——某天在 Zod 那邊加了
欄位卻忘了同步，檢查通過、執行期炸掉。

企劃書 §4.2 要避免的正是同一個病：規則有兩個地方可以放，
就會有一個地方漏掉。單一事實來源不能為了語言偏好讓步。

## 適合放這裡的東西

- 舊格式轉檔（例如萬華主線〈回家的畫〉→ 人格卡格式）
- 各站台詞量統計、內容盤點報表
- 文字批次清理
- 內容生成輔助

## 慣例

- 虛擬環境放 `tools/.venv/`（已在 .gitignore）
- 產出物放 `tools/out/`（已在 .gitignore），不要直接覆寫 `content/`
  ——轉檔結果要人看過再手動搬進去
